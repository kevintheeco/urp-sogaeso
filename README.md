## ✏️ 대표님이 직접 글자 고치는 법 (코드 몰라도 됩니다)

1. 이 저장소에서 **`index.html`** 파일을 클릭합니다.
2. 오른쪽 위 **연필(✏️) 아이콘**을 누릅니다.
3. `◆◆◆ ... ◆◆◆` 로 표시된 구역을 찾아 **한글만** 바꿉니다.
   - `<` `>` `"` 같은 기호는 건드리지 마세요.
4. 아래 초록색 **Commit changes** 버튼을 누릅니다.
5. **1~2분 뒤** 라이브 주소에 자동 반영됩니다.

> 크게 바꾸고 싶거나 새 페이지·이미지를 넣고 싶으면 요나단에게 말씀하세요.
