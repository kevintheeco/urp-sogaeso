브랜드 **니가 교수 (You Are Professor)** — 학생이 스스로 설명하게 만들고, 그 과정을 분석해 약점을 채우는 자기주도 학습 플랫폼.

**라이브 주소:** https://kevintheeco.github.io/urp-sogaeso/

이 한 페이지로 팀 누구나 (하나은행 멘토 포함) URP를 소개할 수 있습니다.

---

## 신앙 버전 / 일반 버전

방문자는 처음 진입할 때 **신앙의 언어 / 담백한 언어**를 고르고, 우측 상단 토글로 언제든 바꿉니다. 선택은 브라우저에 기억됩니다.

- `class="only-faith"` → 신앙 버전에서만 보임 (새벽 기도, 약점을 들어 쓰신 은혜, 고린도후서 12:9)
- `class="only-plain"` → 일반 버전에서만 보임 (같은 이야기의 담백한 버전)

## ✏️ 대표님이 직접 글자 고치는 법 (코드 몰라도 됩니다)

1. 이 저장소에서 **`index.html`** 클릭 → 오른쪽 위 **연필(✏️)**
2. `◆◆◆ ... ◆◆◆` 로 표시된 구역에서 **한글만** 수정 ( `< > "` 기호는 그대로 )
3. 초록색 **Commit changes** → 1~2분 뒤 사이트 반영

크게 바꾸거나 이미지·영상·모션을 넣고 싶으면 요나단에게 말씀하세요.

## 구성

히어로 → 우리는 누구인가 → **대표의 이야기(믿음/일반 전환)** → 무엇을 만드는가 → **살아있는 3축 밴다이어그램** → 왜 지금 → 세 갈래(B2C·B2B·B2G) → 우리가 가려는 곳 → 팀.

원자료: 대표 시작 이야기(니가 교수_mystory), 경쟁 심층분석(3축 21개사). 밴다이어그램은 웹 네이티브 SVG 애니메이션 — 추후 힉스필드 모션그래픽으로 교체 가능.
